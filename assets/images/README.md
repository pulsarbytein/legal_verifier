# Image Assets for LegalVerifier Project

Place your high-resolution PNG/SVG/JPEG images in their respective subdirectories:

- `assets/images/creator-protection/` -> Hero photos, creator 5-step sequence, phone mockup
- `assets/images/virtual-office/` -> LVVO interior photos, office cards, city skyline banner
- `assets/images/defence-services/` -> Army/Navy/AirForce banners, emblem graphics
- `assets/images/dispute-resolution/` -> ODR flow diagrams, category graphics
